# ⚡ SaberLab - Plataforma Educativa Gamificada de Ciencias y Electricidad

Plataforma educativa moderna para el aprendizaje interactivo de electricidad, electrónica, física y tecnología, construida con **React 19 + Vite + Cloudflare D1 + Cloudflare Pages**.

## 🛠️ Comandos de Desarrollo

```bash
# Iniciar servidor local de desarrollo
npm run dev

# Compilar para producción (comprobación de tipos y 0 errores)
npm run build

# Analizar linter
npm run lint
```
